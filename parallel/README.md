# Параллельный метод Якоби (MPI)

## Описание
Решение системы линейных уравнений методом Якоби с использованием MPI.

## Файлы
- `jacobi.c` - исходный код
- `jacobi1.job` - скрипт запуска на кластере (SLURM)
- `plot.gp` - скрипт для построения графиков (gnuplot)
- `res.txt` - результаты измерений времени
- `matric.pdf` - график ускорения
- `курсовая.pdf` - отчет о выполнении курсовой
